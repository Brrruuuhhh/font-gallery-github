# Галерея шрифтов

Каталог с поиском, фильтрами, предпросмотром, сравнением до пяти шрифтов, скачиванием ZIP и готовым CSS. Сервер — PHP и PostgreSQL, административная панель — Vue с авторизацией JWT.

## Что установить

- PHP 8.4–8.5 с расширениями `pdo_pgsql`, `mbstring`, `fileinfo`, `iconv`, `zip`; для проверок HTTP также `curl`.
- Composer 2, Node.js 24.12+ и npm. Версия для nvm указана в `admin-ui/.nvmrc`.
- PostgreSQL (проект проверен с версией 18). Служба БД должна быть запущена; для первоначальной настройки нужна учётная запись с правами создания баз и ролей.

Команды выполняются из корня скачанного проекта. Для установки на Windows используйте WSL: ввод скрытого пароля в команде создания администратора требует утилиту `stty`, доступную в Linux и macOS.

## Установка и первый запуск

Установите зависимости:

```sh
composer install
npm --prefix admin-ui ci
```

Укажите данные **своего** администратора PostgreSQL в том же терминале. Например, для локального сервера с пользователем `postgres`:

```sh
export PGHOST=127.0.0.1
export PGPORT=5432
export PGUSER=postgres
export PGPASSWORD
read -rs PGPASSWORD
```

После `read -rs PGPASSWORD` введите пароль PostgreSQL и нажмите Enter; символы не отображаются. Если пароль не требуется, нажмите Enter. На macOS с PostgreSQL из Homebrew имя пользователя БД обычно совпадает с именем пользователя системы: вместо `postgres` укажите его. При необходимости сначала запустите службу PostgreSQL.

Подготовьте БД, импортируйте шрифты и создайте администратора сайта:

```sh
php scripts/setup.php
php scripts/import-fonts.php
php scripts/setup-admin.php
unset PGPASSWORD
php scripts/start.php
```

При создании администратора задайте собственные логин и пароль. Логин — 3–64 латинские буквы, цифры, точки, дефисы или подчёркивания; пароль — 12–72 байта, для простого ввода используйте латинские символы. Пароль нужно ввести дважды.

Сайт: <http://127.0.0.1:8000/>. Админка: <http://127.0.0.1:8000/admin/>. Войдите с созданной учётной записью. В первоначальном каталоге 15 шрифтов; файлы и обязательные лицензии включены в `database/fixtures/`.

Команда запуска собирает админку и запускает общий сервер. Остановка — `Ctrl+C`. В дальнейшем достаточно запустить PostgreSQL и выполнить `php scripts/start.php`. Проверка готовности: `php scripts/start.php --check`.

Данные подключений и секрет JWT создаются автоматически в `.private/`; публиковать эту папку не нужно. Используйте отдельный локальный PostgreSQL без ранее созданных ролей `font_gallery_app` и `font_gallery_admin`. Настройка создаёт базу `font_gallery`; повторный импорт сохраняет существующие записи. Установленные зависимости и сборка исключены из Git.

## Быстрая проверка

Без запущенного веб-сервера:

```sh
composer test
php tests/font-download.php
node --test tests/public-preview.mjs
npm --prefix admin-ui test
```

При работающем сайте в другом терминале:

```sh
php tests/web-entry.php
php tests/integration.php --read-only
```

Последняя проверка рассчитана на первоначальный набор шрифтов и не изменяет данные. В интерфейсе можно проверить поиск, предпросмотр и сравнение, затем создать, изменить и удалить собственную запись в админке.

Для работы над Vue с автоматическим обновлением страниц дополнительно выполните `npm --prefix admin-ui run dev` и откройте <http://127.0.0.1:5173/admin/>; общий сервер и БД должны продолжать работать. Для обычного запуска отдельный Vite-сервер не нужен.
